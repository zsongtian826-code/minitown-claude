# 🏘️ ミニタウン (minitown-claude)

小さな街で、3人の住人(**アオイ・ミナ・レン**)が自分で考えて暮らす、ブラウザの箱庭シミュレーターです。
プレイヤーが何もしなくても、起きて・出勤して・食べて・おしゃべりして・帰って・眠ります。
天気を変えたり差し入れを送ったりして、世界にちょっかいを出すこともできます。

- 外部のAI API・サーバー・DBは使っていません(すべてブラウザ内のプログラムで動きます)
- Vite + React + TypeScript + CSS(描画は Canvas 2D、絵はすべてコードで描いた自作)
- 状態は `localStorage` に自動保存されるので、閉じても続きから再開できます

## 遊び方

| 操作 | 内容 |
| --- | --- |
| ⏸ 一時停止 / ▶ 再開 | 世界の時間を止める・進める(スペースキー) |
| 1× / 10× / 60× | 現実の1秒 = ゲーム内の1分 / 10分 / 60分(キー 1・2・3) |
| キャラクターをクリック | 詳細(行動・場所・目的地・理由・空腹/疲労/気分・関係値)を表示。目的地までの道すじも出ます |
| ☔ 突然の雨 / 🍰 差し入れ / ☕ 休憩のお誘い | 世界へのイベント介入 |
| 🆕 新しい世界 | シードを指定して最初から(いまのセーブを上書きすることを確認します) |
| 📷 画像で保存 | マップのスクリーンショット |

パネルは **住人 / ログ / 会話 / 関係 / 振り返り** の5つ。スマホでは、マップの下に情報パネルが並びます。

## 実装した機能

必須: 3人の自律行動(個性つき)、5つの施設と2D街マップ(15×10以上 → 28×18)、A*経路探索、ワールドクロック(1日目 07:00 開始、一時停止/1/10/60倍速)、
基準スケジュールと状態による逸脱・復帰、ルールベース会話と会話ログ、天候(晴/曇/雨・シード付き乱数)、3種類のユーザー介入イベント、イベントログ(400件保持)、
シード指定と完全な再現性、セーブ/ロード(バージョン付き・検証付き)、PC/スマホ対応UI。

追加: 吹き出し・表情変化・行動アイコン、昼夜の色と夜の灯り、雨のアニメーション、行動の理由の表示、次の行動の予測、数値の推移グラフ(スパークライン)、
人間関係マップ、一日の振り返り、マップのスクリーンショット、目的地までの道すじ表示。

## シミュレーション設計

エンジン(`src/sim/`)はUIに一切依存せず、`Simulation` クラス1つを通して動かします。UI(`src/ui/`)は世界を読んで描くだけです。

```
src/sim/
  rng.ts         シード付き乱数(mulberry32)。状態は32bit整数1つ
  clock.ts       ワールドクロック(world.tick が唯一の時間)
  map.ts         タイル・施設・席(スポット)・A*・距離
  profiles.ts    3人の個性(係数の表)
  needs.ts       空腹・疲労・気分の変化ルール(式と表)
  behavior.ts    自律行動の頭脳(Utility AI)
  engine.ts      1分ごとの進行(移動・到着・計画の終了・乗り換え)
  chat.ts        会話の開始・進行・終了、関係値と気分の変化
  dialogue.ts    ルールベースの会話文生成
  weather.ts     天候(変更の入口は setWeather ただ一つ)
  events.ts      ユーザー介入イベント
  save.ts        セーブ・ロード・検証
  runner.ts      固定ステップ実行(実時間 → tick数)
  invariants.ts  「あり得ない状態」を検出する整合性チェック(テスト・保存時に使用)
```

### 時間管理
`world.tick`(= ゲーム内1分)が唯一の時間です。日付と時刻は tick から計算するだけで、別に持ちません(0時をまたいでも矛盾しません)。
`FixedStepRunner` は「経過した実時間 × 速度」から**何tick進めるか**だけを決めます。結果は tick の回数だけで決まるので、描画のフレームレートやPCの速さで世界は変わりません。
一時停止中は tick が進みません。速度を上げると表示だけでなく、移動・空腹・疲労などの内部状態も同じように進みます。

### 自律行動: Utility AI を採用した理由
行動の候補(就寝・朝の準備・仕事・食事・休憩・自由時間・会話 × 場所)を並べ、それぞれに**欲求の強さ(点数)**を付け、最大のものを選びます。点数は
`基準スケジュール × 体の状態(空腹・疲労・気分) × 性格 × 天候 × 距離` で決まります。基準スケジュール(7:00起床・9:00勤務・12:00昼食・13:00再開・17:00終了・18:00自由・23:00就寝)は点数を上げる要素の1つにすぎず、
空腹や疲労が強ければ仕事より食事・休憩が勝ち、雨なら公園より屋内が選ばれ、予定が崩れても就寝や出勤の点数が時刻とともに上がって生活リズムに戻ります。

選んだ理由 - 欲求を同じ物差しで比べられる/「なぜ今それをしたか」を点数の内訳で説明できる(UIの「行動の理由」)/性格を係数の違いで表せる/状態機械のような条件の組み合わせ爆発が起きにくい。

切り替えの連発を防ぐ仕組み: ①いまの計画への粘着(性格の頑固さ。アオイ 0.45、レン 0.10)、②計画開始から12分は乗り換えない(緊急時を除く)、
③直前と同じことを150分以内に繰り返すとペナルティ、④移動中の乗り換えは条件を厳しく、⑤睡眠・朝の準備・食事・お茶会は中断しない。
雨・閉店(カフェ22時/オフィス20時)のときだけ「見直し」を強制します。

### 状態管理
各キャラクターは独立した状態(位置・行動・計画・経路・空腹度/疲労度/気分/関係値 0〜100・記憶)を持ち、すべて0〜100にクランプされます。変化は `needs.ts` の表(分あたり)です。

| 行動 | 空腹 | 疲労 | 気分 |
| --- | --- | --- | --- |
| 睡眠 | +0.04 | −0.15 | – |
| 朝の準備(朝食つき) | −1.1 | 0 | +0.05 |
| 移動 | +0.14 | +0.12 | – |
| 仕事 | +0.14 | +0.13 | 性格(アオイ +0.012 / ミナ −0.004 / レン −0.025) |
| 食事 | −1.5 | −0.02 | +0.10(カフェは+0.06) |
| 休憩 | +0.12 | −0.20(自宅はさらに −0.05) | +0.05 |
| 自由時間 | +0.12 | −0.05 | +0.09 |
| 会話 | +0.12 | +0.05 | 会話の終了時にまとめて |

空腹・疲労の増加には個性の係数(例: レンは空腹の進みが1.1倍)がかかり、気分は性格ごとの基準値へ少しずつ戻り、空腹75以上・疲労80以上・雨の屋外でさらに下がります。

「現在の行動」は計画(Plan)から決まり、実際の位置と矛盾しないことを `invariants.ts` が毎tick検査できます(睡眠中は自宅のベッド、勤務中はオフィスの自席、会話中は二人とも静止して同じ場所の近く、など)。

### 経路探索
4方向の **A\***(マンハッタン距離ヒューリスティック、草地は道・床より移動コストが高く、道を選びやすい)。同点のときの並びも固定なので結果は毎回同じです。
壁・木・水・家具は通れず、建物には入口(ドア)からしか入れません。全施設・全席の相互到達性はテストで保証しています。
キャラクター同士は通路でぶつからない(重なって通れる)ので、互いに進路を塞ぎ続けることはなく、席は予約制なので同じ施設を同時に使っても重ならないようにしています。

### 会話
外部AIなしのルールベースです。会話は「二人とも立ち止まっていて、同じ場所のすぐ近く(2マス以内)にいて、どちらも睡眠中・移動中・仕事中でない」ときだけ始まります。
話しかけた人が相手のそばまで歩いていき、相手は性格・体調・関係値から応じるかを決めます。ペアごとのクールダウンもあります。
セリフは「話題(あいさつ/天気/空腹/疲れ/仕事/場所/気分/雑談/出来事)× 話し手の口調」のテンプレートから、時間帯・場所・天候・気分・関係値・最近の出来事に合うものだけを候補にして選びます(直近のセリフは選ばれにくい)。
天候や出来事に触れるテンプレートには必ず使える条件が付いていて、「雨が止んだ」は本当に直前に雨が止んだときだけ使われます(テストで検証)。
終了時に関係値と気分が、二人の社交性・気分・関係値から計算されて変わります。

### 天候
晴れ・曇り・雨を1時間ごとにシード付き乱数で遷移させます。天気を変える入口は `setWeather` ただ1つで、ログの文章もここが(変更前→変更後)から作るため、
内部状態・表示・ログ・会話が食い違いません。雨が降り出すと屋外にいる人は行き先を見直します。

### イベント
- ☔ **突然の雨**: 天気を雨に変更(2〜3時間は自然変化で止まない)。すでに雨なら延長(上限4時間)
- 🍰 **差し入れ**: オフィスにいる起きている人だけ、空腹 −25・気分 +10。30分は新しい差し入れを受け付けない
- ☕ **休憩のお誘い**: 起きている人がそれぞれ性格・体調・状況から参加を判断し、参加者はカフェへ向かって交流。睡眠中は不参加。90分後に通常の行動へ戻る

同じ種類のイベントを同じ瞬間に重ねて発火することはできず、連打しても数値は範囲内・状態は整合のままです。

### 再現性とセーブ
乱数は `Rng` として注入され、シミュレーション内で `Math.random`/`Date` は使っていません(テストが検査)。同じシード・同じイベント・同じステップ数なら完全に同じ結果です。
セーブは `localStorage`(キー `minitown-claude:save`)に、バージョン・時刻・天候・全キャラ状態(関係値・行動・目的地)・ログ・会話・シード・乱数状態を保存します。
読み込み時は全項目を検証し(範囲・型・歩ける座標・存在する場所・整合性チェック)、壊れていたら理由を表示して新しい世界を始めます(アプリは落ちません)。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 自動テスト(Vitest)
npm run build      # 型チェック + 本番ビルド(dist/)
npm run simulate -- 12345 72   # ヘッドレスで72時間走らせてログを表示
npm run stats                  # 複数シードで1日の行動時間などを集計
```

## テスト

`src/sim/__tests__/` に自動テストがあります。主なもの:
3人の独立行動/時間の進行と0時またぎ/一時停止/速度/壁を通らない・全施設に到達できる/空腹で食事・疲労で休憩や就寝/全員が帰宅して眠り翌朝起きる/睡眠中に会話しない/会話で関係値が変わる/
雨イベントで内部天候が変わる・天候ログと内部状態の一致・会話の天気の矛盾なし/差し入れは対象者だけ/イベント後に通常行動へ復帰/同じシードで同じ結果/
保存→再読み込みで続きが同一/壊れたセーブの拒否(ランダムに壊した400通り)/新しい世界で初期化/24時間・72時間(7シード)・30日の安定性。
